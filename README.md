# Proyecto 2 IA: Clasificación de gatos y perros con fine tuning de VGG16 y ResNet50
## Juan Sebastian García Perez

Proyecto de visión artificial: clasificador capaz de distinguir automáticamente si en una fotografía aparece un gato o un perro, aplicando fine tuning sobre redes convolucionales preentrenadas.

**BD seleccionada:** Cats vs Dogs, cargada desde TensorFlow Datasets https://www.tensorflow.org/datasets/catalog/cats_vs_dogs

**Tipo de problema:** Aprendizaje supervisado - clasificación binaria de imágenes.
